# SARIMA Counterfactual Baseline

The first layer of our hybrid methodology establishes a rigorous baseline using a Seasonal AutoRegressive Integrated Moving Average (SARIMA) model. This model estimates what Morocco's electricity demand would look like in the *absence* of the 2030 World Cup.

## Purpose of the Counterfactual

In observational studies and quasi-experiments where randomized control trials are impossible, causal inference relies on constructing a counterfactual. For the 2030 World Cup, we cannot observe a "control Morocco" that doesn't host the event. The SARIMA model provides this synthetic control, allowing us to isolate and inject the event uplift as a distinct delta.

## Model Formulation

Based on the EDA and Stationarity Analysis, the demand series $y_t$ is modeled as:

$$\log(1 + y_t) \sim \text{SARIMA}(p, d, q) \times (P, D, Q)_s$$

Where:
- **$s = 12$**: Annual seasonality (monthly data).
- **$d = 1$**: First differencing to remove the stochastic trend.
- **$D = 1$**: Seasonal differencing to remove the stable seasonal pattern.
- **$p, q, P, Q$**: Autoregressive and moving average parameters selected via AIC minimization.

## Model Selection

The final model specification is determined using the `StatsForecast AutoARIMA` algorithm, which exhaustively searches the parameter space and selects the model minimizing the Akaike Information Criterion (AIC).

For the final Morocco deployment (trained on data up to Dec 2025), the selected model is:

**$\text{SARIMA}(1, 1, 1) \times (0, 1, 2)_{12}$**

## Generating the Counterfactual

The fitted model projects demand from January 2026 through December 2030. Critically, because the model is linear in log-space, its native predictions represent the geometric expectation when transformed back to natural scale. 

To maintain proper statistical coverage, prediction intervals (85% confidence level) are generated by the model in log-space and subsequently back-transformed individually via $f(x) = \exp(x) - 1$.

This counterfactual trajectory serves as the foundational curve upon which the Neural Event Kernel will overlay the World Cup shock.
